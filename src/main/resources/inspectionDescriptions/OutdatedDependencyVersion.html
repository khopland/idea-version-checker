Reports dependency, plugin and wrapper versions that have a newer stable release.

Use Alt+Enter to update to the newest patch, minor or major release. Tools | Versions updates a whole file or project.

Supported files: pom.xml, package.json, Gradle build scripts, libs.versions.toml, and the Maven and Gradle wrapper properties. The minimum release age in Settings | Tools | Version Checker hides recent Maven, Gradle and wrapper releases.
