Reports dependency, plugin, toolchain, action and image versions that have a newer stable release.

Use Alt+Enter to update to the newest patch, minor or major release. Tools | Versions updates a whole file or project.

Supported files: pom.xml, package.json and pnpm-workspace.yaml, Gradle build scripts, gradle.properties and libs.versions.toml, the Maven and Gradle wrapper properties, .nvmrc, .node-version, .sdkmanrc and .tool-versions, GitHub Actions workflows and action.yml, Dockerfiles and Compose files.

The minimum release age in Settings | Tools | Version Checker hides recent Maven, Gradle, wrapper and npm releases.

To keep a version on purpose, add a suppress comment from the Alt+Enter menu, for example <!--suppress OutdatedDependencyVersion --> in a POM or #noinspection OutdatedDependencyVersion in libs.versions.toml. In package.json, Keep this version adds the package to "versionChecker": {"keep": {…}}. The update actions skip kept versions.
