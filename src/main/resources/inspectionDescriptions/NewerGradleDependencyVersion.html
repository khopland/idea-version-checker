Reports Gradle library and BOM dependencies with a newer stable version available from the linked project's Gradle repositories. Checks use IntelliJ IDEA's linked Gradle project, wrapper and JVM configuration.

Supports fixed numeric stable versions in build.gradle and build.gradle.kts, and literal library versions or simple version.ref entries in the default local gradle/libs.versions.toml catalog. Comparisons use declared versions, not installed, locked or platform-selected versions.

Use Settings → Tools → Version Checker to configure highlighting for version changes and project deprecation rules. Available updates are warnings by default; dependencies marked deprecated by project rules are errors by default.

The quick fix updates the declared version. A shared catalog version can be updated only when every library using it has an update to the same version. Unchanged, unsupported or conflicting consumers, and references shared with catalog plugins, require manual review. A catalog version change affects every consumer of that version.

Save Gradle build files before checking. Use Tools → Check Versions → Refresh Current File or Refresh Whole Project to refresh results. Tools → Update Versions → Current File / Whole Project previews patch, minor or major updates.

Dynamic versions, prereleases, interpolated or shared build-script properties, map notation, dependency customization blocks, constraints, plugin versions and custom or published catalogs require manual review.

Updates change version declarations only. Reload the Gradle project afterward and synchronize dependency locks if the build uses locking.
