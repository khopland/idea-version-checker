Reports entries in gradle/libs.versions.toml that nothing uses:
  • a [versions] entry without a version.ref or libs.versions.x,
  • a [libraries] alias that no build script uses as libs.x and no bundle lists,
  • a [plugins] alias that no build script uses as libs.plugins.x.

The alias junit-api is used as libs.junit.api, or as "junit-api", for example in findLibrary("junit-api"). Build scripts, buildSrc and included builds that import the catalog count. The check is skipped when the settings script registers another catalog.

Use Alt+Enter to remove the entry.
