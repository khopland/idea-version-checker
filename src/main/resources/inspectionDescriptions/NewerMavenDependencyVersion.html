Reports Maven dependencies and build plugins with a newer stable version available from the project's Maven repositories.

Update messages are warnings by default. Configure patch, minor, major, other version changes, and deprecated/relocated artifact severity under Settings → Tools → Version Checker. Explicitly deprecated dependencies/plugins and Maven relocation notices are errors by default, including when no version update is available.

Checks use IntelliJ IDEA's Maven settings and active profiles. Results are cached for ten minutes. Use Tools → Check Versions → Current File or Whole Project to refresh them.

The quick fix updates a literal version or an exact property reference declared in the same POM. Updating a shared property affects every declaration using it.

For inherited dependency versions, choose Override version locally to add or replace the child dependency's version, or Update parent version to change its controlling version/property in an imported, non-ignored parent POM. The parent action names the POM it edits and can follow multiple parent levels. Shared consumers inherit that update. Changes to POMs or configuration invalidate these fixes. External parent declarations and composite expressions require manual review.

Build plugins in build/plugins and build/pluginManagement/plugins are supported. Snapshots, version ranges, reporting plugins, build extensions and transitive dependencies are outside this inspection's scope.
