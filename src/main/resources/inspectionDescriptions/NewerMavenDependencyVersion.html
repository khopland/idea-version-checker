Reports Maven dependencies with a newer stable version available from the project's Maven repositories.

Update messages are warnings by default. Configure patch, minor, major, other version changes, and deprecated/relocated dependency severity under Settings → Tools → Maven Version Checker. Explicitly deprecated dependencies and Maven relocation notices are errors by default, including when no version update is available.

Checks use IntelliJ IDEA's Maven settings and active profiles. Results are cached for ten minutes. Use Tools → Check Maven Dependency Versions to refresh them.

The quick fix updates a literal version or an exact property reference declared in the same POM. Updating a shared property affects every dependency using it. Inherited versions need to be changed at their source.

Snapshots, version ranges, build plugins and transitive dependencies are outside this inspection's scope.
