Reports declared dependencies that bring in packages with known vulnerabilities from OSV.dev. The warning is on the declared dependency, and names the vulnerable package and the path to it.

Maven projects are checked from the dependency tree of the last import, and npm and pnpm projects from package-lock.json or pnpm-lock.yaml. The check is off until you turn on Check for known vulnerabilities in Settings | Tools | Version Checker. It sends the names and versions of the resolved packages to osv.dev.

Use Alt+Enter to pin the package in <dependencyManagement>, npm overrides or pnpm overrides at the lowest stable version that fixes every reported vulnerability. An npm or pnpm override covers every copy in the vulnerable major, so it offers the highest version any of them needs. To keep a dependency on purpose, add a suppress comment from the Alt+Enter menu, for example <!--suppress VulnerableTransitiveDependency --> in a POM. package.json cannot have comments, so turn the inspection off there instead.
