Reports declared dependencies that bring in packages with known vulnerabilities from OSV.dev. The warning is on the declared dependency, and names the vulnerable package and the path to it.

Only Maven projects are checked for now, from the dependency tree of the last import. The check is off until you turn on Check for known vulnerabilities in Settings | Tools | Version Checker. It sends the names and versions of the resolved packages to osv.dev.

Use Alt+Enter to pin the package in <dependencyManagement> at the lowest stable version that fixes every reported vulnerability. To keep a dependency on purpose, add a suppress comment from the Alt+Enter menu, for example <!--suppress VulnerableTransitiveDependency -->.
