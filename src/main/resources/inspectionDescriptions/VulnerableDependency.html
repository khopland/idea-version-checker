Reports declared Maven, Gradle and npm dependency versions with known vulnerabilities from OSV.dev.

The check is off until you turn on Check for known vulnerabilities in Settings | Tools | Version Checker. It sends the names and versions of declared dependencies to osv.dev. A project set up under Version Checker | Nexus IQ sends them to its Nexus IQ server instead, and then only vulnerabilities that the application's policies flag and that are not waived are reported. Alt+Enter opens the application's report in Nexus IQ, where you can waive them. Vulnerable transitive dependency reports the packages they bring in, in Maven, npm, pnpm, Yarn and Bun projects.

An npm dependency is checked at the version its lockfile installs, or else at the declared version.

Critical and high severity show as errors at the default level. Use Alt+Enter to update to the lowest stable version that fixes every reported vulnerability.

To keep a version on purpose, add a suppress comment from the Alt+Enter menu, for example <!--suppress VulnerableDependency --> in a POM or //noinspection VulnerableDependency in a Gradle script.
