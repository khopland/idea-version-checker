Reports declared Maven, Gradle and npm dependency versions with known vulnerabilities from OSV.dev.

The check is off until you turn on Check for known vulnerabilities in Settings | Tools | Version Checker. It sends the names and versions of declared dependencies to osv.dev. Vulnerable transitive dependency reports the packages they bring in, in Maven, npm and pnpm projects.

Critical and high severity show as errors at the default level. Use Alt+Enter to update to the lowest stable version that fixes every reported vulnerability.

To keep a version on purpose, add a suppress comment from the Alt+Enter menu, for example <!--suppress VulnerableDependency --> in a POM or //noinspection VulnerableDependency in a Gradle script.
