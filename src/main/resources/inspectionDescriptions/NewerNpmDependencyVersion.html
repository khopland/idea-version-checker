Checks dependency versions in package.json through read-only npm registry queries using IntelliJ's configured local Node.js interpreter and npm. npm evaluates registry and authentication settings from .npmrc.

Updates dependencies, devDependencies and optionalDependencies. Peer compatibility requires manual review. Exact versions, caret/tilde ranges and npm aliases can be updated; local/workspace dependencies and complex selectors need manual review. Comparisons use the declared version or range floor, not installed versions.

When a registry dependency can be updated in multiple workspace manifests, Alt+Enter offers a local update or an update across the workspace root and its member packages. Each declaration retains its range/alias syntax. Newer versions, peer declarations and unsupported selectors remain unchanged. Workspace changes apply in one undoable command.

Use Settings → Tools → Version Checker to configure highlighting. Deprecated versions default to red; available updates default to yellow.

Tools → Update Versions → Current File / Whole Project previews manifest changes. Lockfiles and installed dependencies are left to IntelliJ's package-manager actions.
