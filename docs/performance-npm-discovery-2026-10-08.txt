IDEA 2025.3.6.1; Gradle Java toolchain 21; macOS arm64
Fixture: 101 manifests, 10,000 declarations; validate one member after ordinary source editing.
Five alternating warm/source-edit samples per implementation, in separate test JVMs.
p95 is nearest-rank (maximum for n=5). No timing threshold is asserted.
Both comparison runs use the same command:
./gradlew test --tests '*NpmSnapshotScalingTest' -PperformanceTrace=true
Measurements cover local currentness validation, not registry work or completed editor rendering.
JIT, filesystem and test-process state can affect comparisons; this is no production speedup claim.
The revised implementation also replaces per-byte formatting with the JDK hex encoder.
