# Acceptance records

Each record applies only to its identified source and plugin archive.
Test totals, IDE versions, and blockers describe that recorded run.
They do not certify the current branch or a new archive.

| Date | Record |
| --- | --- |
| 22 October 2026 | [Candidate validation and acceptance limits](2026-10-22/README.md) |

The retained record includes candidate identities, checksums, results, and limits.
Some local logs and temporary IDE profiles are unavailable in a fresh checkout.
An unavailable evidence file is not a passed check.
Superseded records remain available in Git history.

Use the [packaged plugin acceptance procedure](../ide-acceptance.md) to validate a new candidate.
See the [release procedure](../releasing.md) for publication instructions.
